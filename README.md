# NoteApp

## Beschreibung
Die NoteApp ist eine einfache Webanwendung zur Erstellung und Verwaltung von Notizen.  
Benutzer können Texte eingeben, speichern und anzeigen lassen.

Dieses Projekt wurde entwickelt, um meine Kenntnisse in HTML, CSS und JavaScript praktisch anzuwenden.

## Funktionen
- Erstellen von Notizen
- Anzeigen gespeicherter Notizen
- Dynamische Aktualisierung der Benutzeroberfläche
- Einfache und übersichtliche Benutzeroberfläche

## Verwendete Technologien
- HTML5
- CSS3
- JavaScript (DOM-Manipulation, Event-Handling)

## Lernziele
- Arbeiten mit dem DOM
- Event-Listener implementieren
- Strukturierung von JavaScript-Code
- Gestaltung einer benutzerfreundlichen Oberfläche

## Projekt starten
Einfach die `index.html` Datei im Browser öffnen.
